Koble til Dota 2 (én gang)

Kjør setup.bat (eller npm run setup). Den finner Dota-mappen og legger inn konfig-filen for Game State Integration.
I Steam: høyreklikk på Dota 2 → Egenskaper → Startalternativer, og legg til -gamestateintegration
For overlay over spillet: Dota 2 → Innstillinger → Video → Visningsmodus Borderless Window.
Start Dota 2 på nytt. Statusen nede til venstre blir grønn når data kommer inn.

Tale (opplesning av tips)

Stemme Hastighet

Tips: installer norsk stemme i Windows (Innstillinger → Tid og språk → Tale → Legg til stemmer → Norsk bokmål) for best uttale.

Overlay over spillet

🪟
Dota Coach-appen (anbefalt): kjør Dota Coach.bat. Du får appvinduet og et gjennomsiktig overlay oppå spillet. Alt+Shift+M flytter og låser, Alt+Shift+C viser og skjuler, Alt+Shift+S slår tale av og på, Alt+Shift+D åpner appvinduet.
⧉
Overlay-vindu i nettleseren: trykk «Overlay-vindu» øverst (Chrome/Edge). Du får et lite vindu som alltid ligger øverst.
📱
Mobil eller nettbrett som skjerm nr. 2: start med start.bat --lan og åpne adressen den skriver ut, på samme Wi-Fi.

Fair play

Coachen bruker bare Valves offisielle Game State Integration. Den ser kun det du selv ser (din hero, gull, items og klokka), og leser ikke minnet til spillet. Den viser ingen info om motspillerne som profiler eller historikk. Meta-tallene kommer fra OpenDota.
